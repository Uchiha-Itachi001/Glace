# AI Assistant Vector Icons

Drop your authentic AI SVGs here! You can use **either Method 1 or Method 2**:

## Method 1: Paste SVG directly into individual files (Easiest)
Simply open the corresponding `.svg` file and replace its contents with your raw `<svg>...</svg>` code:

- `claude.svg` — Anthropic Claude
- `chatgpt.svg` — OpenAI ChatGPT / Codex
- `cursor.svg` — Cursor IDE
- `copilot.svg` — GitHub Copilot
- `mscopilot.svg` — Microsoft Copilot
- `windsurf.svg` — Codeium Windsurf
- `ollama.svg` — Ollama
- `lmstudio.svg` — LM Studio
- `antigravity.svg` — Google Gemini / Antigravity
- `deepseek.svg` — DeepSeek
- `grok.svg` — xAI Grok
- `kimi.svg` — Moonshot Kimi

---

## Method 2: Paste SVG string or Data URI into `icons.json`
If you prefer keeping everything in one JSON file, paste the SVG markup or Data URI into `icons.json`:

```json
{
  "claude": "<svg ...>...</svg>",
  "chatgpt": "<svg ...>...</svg>"
}
```

---

## Automatic Fallback
If any file is empty or not yet filled, Glace automatically falls back to its crisp built-in vector glyph with zero errors!
